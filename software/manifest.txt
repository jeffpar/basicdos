#
# BASIC-DOS Distribution Manifest
#
# Each [section] lists the files (relative to the repository root, with optional
# wildcards) that belong in the corresponding folder of a BASIC-DOS disk:
#
#   ROOT     the root directory, in order; "CONFIG.SYS" stands for each disk's own
#            CONFIG.SYS (followed by AUTOEXEC.BAT, if its SHELL lines run one)
#   EXT      all the external BASIC-DOS utilities (including BASIC programs) and
#            device drivers (distribution)
#   DEMOS    demo programs (distribution)
#   SAMPLES  the PC DOS 1.00 BASIC samples (distribution)
#   TESTS    BENCH.BAS, STRESS.BAT, and REGRESS.BAT (which runs the tests in
#            TESTS/REGRESS)
#   TESTS/REGRESS  the regression tests (which tools/tests/quick.sh runs, too)
#   TESTS/MISC  other test programs (eg, GFXTEST.BAS, which needs a CGA, and
#            the BAT and EXE versions of PRIMES)
#   TOOLS    tools used for testing (DISKREAD, DISKWRIT, SYMDEB, and MSBASIC)
#
# A section named FOLDER/SUBFOLDER (eg, DEMOS/WOLF3D) is a subfolder of FOLDER,
# and a file inside a disk image can be listed as the image's path (which PCJS's
# diskimage.js resolves) followed by the file's path within the image.
#
# gulpfile.js builds the BASICDOS-360K distribution diskette and every demo
# diskette with ROOT, EXT, DEMOS, and SAMPLES, the BASICDOS-360K-TESTS diskette
# with TESTS (and its subfolders) and TOOLS, and the BASICDOS-10MB hard disk with
# all of them (plus DEMOS/WOLF3D, the WOLF3D.BAT and JIVE files that only it has
# in DEMOS, SRC, and the build tools in TOOLS).  tools/tests/prep.sh copies EXT
# into each test configuration's EXT folder, DEMOS and TESTS into its TESTS
# folder, TESTS/REGRESS and TESTS/MISC into its TESTS\REGRESS and TESTS\MISC
# folders, and TOOLS into TOOLS.
#
