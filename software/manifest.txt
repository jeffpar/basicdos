#
# BASIC-DOS Distribution Manifest
#
# Each [section] lists the files (relative to the repository root, with optional
# wildcards) that belong in the corresponding folder of a BASIC-DOS disk:
#
#   ROOT     the root directory, in order; "CONFIG.SYS" stands for each disk's own
#            CONFIG.SYS (followed by AUTOEXEC.BAT, if its SHELL lines run one)
#   BIN      BASIC-DOS utilities (including BASIC programs) and drivers (distribution)
#   SAMPLES  the PC DOS 1.00 BASIC samples (distribution)
#   DEMOS    the programs that the demos run
#   TESTS    DIR.BAS, STRESS.BAT, and MISC.BAT, which runs the tests in TESTS/MISC
#   TESTS/MISC  the test programs
#   TOOLS    tools used for testing (DISKREAD, DISKWRIT, SYMDEB, and MSBASIC)
#
# A section named FOLDER/SUBFOLDER (eg, DEMOS/WOLF3D) is a subfolder of FOLDER,
# and a file inside a disk image can be listed as the image's path (which PCJS's
# diskimage.js resolves) followed by the file's path within the image.
#
# gulpfile.js builds every demo diskette with ROOT, BIN, SAMPLES, and DEMOS, the
# BASICDOS-360K-TESTS diskette with TESTS, TESTS/MISC, and TOOLS, and the
# BASICDOS-10MB hard disk with all of them (plus DEMOS/WOLF3D, the WOLF3D.BAT and
# JIVE files that only it has in DEMOS, SRC, and the build tools in TOOLS).
# tools/tests/prep.sh copies BIN into each test configuration's BIN folder, DEMOS
# and TESTS into its TESTS folder, TESTS/MISC into TESTS\MISC, and TOOLS into
# TOOLS.
#
