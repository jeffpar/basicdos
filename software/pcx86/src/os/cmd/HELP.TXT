ABS(*x*)
Returns the absolute value of *x*.

ARG$[(*n*)]
Returns argument *n* from the command line that ran the current BAS or BAT file (0 is the file's name), or all the arguments if *n* is omitted.  Quoted arguments can contain spaces.

ASC(*string*)
Returns the character code (0-255) of the first character of *string* (or 0 if *string* is empty).

ATN(*x*)
Returns the arctangent of *x*, in radians.

AUTO [*line*][,*increment*]
Prompts for program lines, starting with *line* (default 10) and adding *increment* (default 10) after each one.  If a line already exists, it's displayed for editing.  To stop, press ENTER on a line with nothing after its number, or press CTRL-C.

CD [*drive*:][*path*]
Changes the current directory of *drive* (or the current drive) to *path*, where directory names are separated by the path character (/ by default, or \ if SWITCHAR is /).  A *path* that begins with the path character starts at the root directory, and .. refers to the parent directory.  If no *path* is specified, the current directory is displayed.  CHDIR is the same as CD.

CDBL(*x*)
Returns *x* as a double.  CSNG is the same, since all floating-point values are double-precision.

CHAIN *file*[,*line*]
Runs the specified BAS file and then ends the program.  The *line* is currently ignored, and other CHAIN options are not supported.

CHDIR [*drive*:][*path*]
Same as CD.

CHR$(*code*)
Returns a one-character string containing the character with the specified *code* (0-255).

CINT(*x*)
Returns *x* rounded to an integer (eg, CINT(2.6) is 3), as assigning it to an integer variable would.

CIRCLE (*x*,*y*),*r*[,[*color*][,[*start*][,[*end*][,*aspect*]]]]
Draws a circle (or ellipse) with radius *r* in a graphics mode, or an arc from the *start* to the *end* angle (in radians), with lines to the center for negative angles.
If *aspect* (the ratio of the y radius to the x radius) is omitted, the circle looks round on a standard display.

CLEAR [[*n*][,[*m*][,*k*]]]
Resets all numeric variables to zero and all string variables to empty strings, and erases all arrays.  The values are ignored.

CLOSE [[#]*n*[,[#]*n*]...]
Closes the specified files (or all files if none are specified).  Files that a program leaves open are closed when it ends.

CLS
Clears the session using the background color and moves the cursor to the top left corner.

COLOR [*foreground*][,[*background*][,*border*]]
Sets the foreground (0-15), background (0-15), and border (0-255) colors of the session.
For blinking colors, use 16-31 for *foreground*, 8-15 for *background*, and 128-255 for *border*.
In SCREEN 1, the values are the background color (0-15) and palette (0 or 1) instead.

COPY *input* [*output*]
Copies the contents of the input file or device to the output file or device, or with wildcards (? and *), every matching file to the output drive or directory (eg, COPY B:/*.BAS).  If *output* is omitted, the current directory is used.

COS(*x*)
Returns the cosine of *x*, where *x* is in radians.

CSNG(*x*)
Same as CDBL.

CSRLIN
Returns the cursor's row, starting at 1.  See also POS.

CURDIR$
Returns the current drive and directory (eg, C:/BASIC), as CD displays them.

CVD(*string*)
Returns the double stored in the first 8 bytes of *string* by MKD$.

CVI(*string*)
Returns the integer stored in the first 2 bytes of *string* by MKI$ (-32768 to 32767).

CVL(*string*)
Returns the integer stored in the first 4 bytes of *string* by MKL$.

DATA *item*[,*item*]...
Defines items for READ to assign to variables, in the order they appear in the program.  An item can be a number or a string; quoted strings can contain commas and colons.

DATE [*date*] [-P]
Sets the system date (or prompts for a date if -P) and then displays the date.
The date must be entered as M-D-Y or M/D/Y, where M is 1-12, D is 1-31, and Y is 0-99 or 1980-2099.
If D or Y are omitted, current values are assumed.

DATE$
Returns the current date as a string in the form MM-DD-YYYY.

DEF *function*(*parms*)[=expression]
Defines a function expression or function block.  Function expressions must fit on a single line and can be defined at any time.
Function blocks may contain multiple lines and must end with a RETURN command.  The function name does not need to begin with FN.
DEF SEG[=*segment*] sets the segment that PEEK and POKE use; without a *segment*, BASIC-DOS's own data segment is used.

DEFDBL [*letter(s)*]
Defines the first letter(s) of variables that will default to double-precision (64-bit) floating-point values.  Variables default to double-precision unless DEFINT or DEFSTR is used (or floating-point is disabled).

DEFINT [*letter(s)*]
Defines the first letter(s) of variables that will default to integer values.

DEFSNG [*letter(s)*]
Same as DEFDBL, since all floating-point values are double-precision.

DEFSTR [*letter(s)*]
Defines the first letter(s) of variables that will default to string values.  Unless DEFSTR is used, all string variables must be defined using the $ suffix.

DEL *file*
Deletes the specified file, or with wildcards (? and *), every matching file (eg, DEL *.TMP).  ERASE is the same as DEL, unless it's erasing arrays.

DELETE *line*[-[*line*]] | -*line*
Deletes the specified range of program lines.  Typing a line number by itself deletes just that line.

DIM *array*(*bounds*)[,*array*(*bounds*)]...
Dimensions one or more arrays, with up to 255 dimensions each (eg, DIM A(10), B$(5,5)).  Each bound is the largest subscript for that dimension.
Arrays that are used without DIM have a largest subscript of 10.

DIR [*filespec*] [-P]
Displays a directory listing of all files matching the given *filespec* (or all files if none is specified).  Subdirectories are listed as <DIR>, and if *filespec* is a directory, its files are listed.

DRAW *string*
Draws lines from the last point, using these commands: U, D, L, R, E, F, G, and H [*n*] (move up, down, left, right, or diagonally), M *x*,*y* (move to *x*,*y*, or relative to the last point if *x* begins with + or -), B (prefix: move without drawing), N (prefix: draw without moving), C *n* (color), and S *n* (scale, in quarters).  Any number can be given as =*variable*; (eg, "M=X;,=Y;").

ECHO [ON|OFF]
Controls the echo of lines in a BAT file.  Every BAT file starts with ECHO OFF; after ECHO ON, echoed lines are displayed with a @ in front, and lines that begin with @ are not echoed.

EDIT *line*
Displays the specified program line for editing.  Press ENTER to store the edited line.

END
Ends the program.  STOP and SYSTEM are the same.

EOF(*n*)
Returns -1 (true) if file *n*, which must be open for INPUT, is at its end, or 0 (false) if not (eg, WHILE NOT EOF(1)).

ERASE *array*[,*array*]...
Erases the specified arrays, so that they can be dimensioned again.  If the first name is not an array, ERASE is the same as DEL.

ERL
Returns the line number of the last error (see ON ERROR), or 0 if the program has no line numbers.

ERR
Returns the number of the last error (see ON ERROR).

ERROR *n*
Simulates error *n* (1-255).

ERRORLEVEL
Constant equal to the return code from the last program executed, or for an internal command, 0 if it succeeded or 1 if it failed.

EXIT
Exits the command processor if there is a previously loaded copy.

EXP(*x*)
Returns e (2.71828...) raised to the power of *x*.

FIELD [#]*n*,*width* AS *variable$*[,*width* AS *variable$*]...
Divides each record of random access file *n* into fields (up to 16): GET # sets each variable to its field, and PUT # writes each variable to its field (see LSET and RSET).

FILES [*filespec*]
Same as DIR.

FIX(*x*)
Returns *x* truncated to an integer (eg, FIX(-2.5) is -2).  See also INT.

FOR *variable*=*start* TO *limit* [STEP *step*]
Executes the lines up to the matching NEXT repeatedly, adding *step* (default 1) to the *variable* each time, until it passes the *limit*.
If the *start* is already past the *limit*, the lines are skipped.

FRE(*x*)
Compacts string memory and returns the number of bytes available.  The argument is ignored.

GET (*x1*,*y1*)-(*x2*,*y2*),*array* or GET [#]*n*[,*record*]
Stores the pixels of the specified rectangle in an integer *array*, in the same format as MSBASIC (see PUT).
With a file number, reads the specified record (or the next one) of random access file *n* into its FIELD variables.

GOSUB *label*
Calls the subroutine at the line with the specified label number; the subroutine ends with RETURN.

GOTO *label*
Transfers program control to the line with the specified label number.

HELP [*command*|*function*]
Displays help for the specified *command* or *function* (eg, HELP MID$), or lists all commands if none is specified.

HEX$(*n*)
Returns the hexadecimal representation of the integer *n*.  Negative values are treated as unsigned 32-bit values (eg, HEX$(-1) is FFFFFFFF).

IF *expression* THEN *command*
Evaluates the *expression*, and if it is TRUE (non-zero), then the *command* is executed.

INKEY$
Returns the next key pressed, without waiting (an empty string if no key was pressed).  Extended keys (eg, cursor keys) return two characters: a null and the key's scan code.

INPUT [*prompt*;|,]*variable*[,*variable*]... or INPUT #*n*,*variable*[,*variable*]...
Reads a line from the keyboard (after displaying the prompt, followed by "? " unless a comma follows the prompt), or with #*n*, from file *n*, and assigns the next item to each variable.  Leading spaces and line breaks are skipped, and an item ends at a comma or line break (or for a number, a space).  A quoted item can contain commas.  Missing keyboard items are empty (or zero).

INSTR([*start*,]*string1*,*string2*)
Returns the position of *string2* within *string1*, searching from position *start* (default 1), or 0 if not found.

INT(*x*)
Returns the largest integer less than or equal to *x* (eg, INT(-2.5) is -3).  See also FIX.

KEY ON|OFF
Accepted for compatibility with MSBASIC, but does nothing, since BASIC-DOS doesn't display function keys.

KEYS
CTRL-E  Up         CTRL-X  Down\
CTRL-S  Left       CTRL-D  Right\
CTRL-W  Home       CTRL-R  End\
CTRL-A  Left Word  CTRL-F  Right Word\
CTRL-G  Del Char\
CTRL-K  Erase to End\
CTRL-V  Toggle Insert\
CTRL-C  Abort\
DELETE  Del Left Char\
ESCAPE  Erase Line
CTRL-ALT-DEL is reserved for terminating programs. Use RESTART to restart the system.

KILL *file*
Same as DEL.

LCASE$(*string*)
Returns *string* with all upper-case letters converted to lower-case.

LEFT$(*string*,*n*)
Returns the leftmost *n* characters of *string*.

LEN(*string*)
Returns the number of characters in *string* (0-255).

LET *variable*=*expression*
Assigns the value of the *expression* to the *variable*.  Values cannot be assigned to predefined variables.

LINE [(*x1*,*y1*)]-(*x2*,*y2*)[,[*color*][,B|BF]]
Draws a line (or with B, a box; or with BF, a filled box) in a graphics mode.  If the first point is omitted, the last point is used.
LINE INPUT [*prompt*;]*variable$* (or LINE INPUT #*n*,*variable$*) reads a whole line from the keyboard (or file *n*) into the string variable.

LIST [*line*][-[*line*]]
Lists all lines (or the specified range of lines) of the currently loaded BAS or BAT program.
To add a line to the program (or replace the line with the same number), type the line with its line number at the prompt.

LOAD *file*
Loads the specified BAS or BAT file, which can be a text file or a tokenized BAS file saved by BASICA or GW-BASIC.  LOAD can't be used inside a BAS or BAT file (yet).

LOC(*n*)
Returns the last record number used by GET # or PUT # for file *n* (or for a sequential file, its position divided by 128).

LOCATE [*row*][,[*col*][,*cursor*]]
Moves the cursor to the specified *row* and *col* (starting at 1,1), and hides (0) or shows (1) the cursor.
The cursor remains hidden until the next input.  Omitted values are unchanged.

LOF(*n*)
Returns the size of file *n*, in bytes.

LOG(*x*)
Returns the natural logarithm of *x*, which must be greater than zero.

LSET *variable$*=*string*
Sets the variable to *string*, left-justified and padded with spaces (or truncated) to the variable's FIELD width (or if it isn't a FIELD variable, its current length).  RSET is the same, but right-justified.

MAXINT
Constant equal to the largest positive integer.

MD [*drive*:]*path*
Creates a new directory.  MKDIR is the same as MD.

MEM [-D]
Displays the total memory, the memory free for running programs (EXEC), and the memory free for BASIC programs, which excludes the part of the command processor that's set aside while running a program (when it can't be set aside, as when more than one session is running, a single "bytes free" value is displayed).
-D also displays every memory block.  In DEBUG builds, -F displays open files, and -S displays active sessions.

MID$(*string*,*start*[,*n*])
Returns *n* characters of *string*, beginning at position *start* (or the rest of *string* if *n* is omitted).

MKD$(*x*)
Returns an 8-byte string containing the double *x* (see CVD), for a random access file.

MKDIR [*drive*:]*path*
Same as MD.

MKI$(*n*)
Returns a 2-byte string containing the integer *n* (see CVI), for a random access file.

MKL$(*n*)
Returns a 4-byte string containing the integer *n* (see CVL), for a random access file.

MOUSE ON|OFF
Resets the mouse and shows (ON) or hides (OFF) the mouse pointer.  If there's no mouse, nothing happens.  The pointer is hidden while graphics statements run, until the next MOUSE function.

MOUSE(*n*)
Returns the next button event (*n* = 0: 0 if none, 1 = left pressed, 2 = left released, 3 = right pressed, 4 = right released), the x (1) or y (2) of that event, or the current x (3), y (4), or buttons (5: 1 = left, 2 = right).
Positions are pixels in graphics modes, or a column and row (starting at 1) in text modes.

NEW
Erases the loaded program, functions, and variables.

NEXT [*variable*[,*variable*]...]
Ends the innermost FOR loop (or, for each *variable*, the FOR loop with that *variable*).

OCT$(*n*)
Returns the octal representation of the integer *n*.

ON *expression* GOTO|GOSUB *label*[,*label*]...
Transfers program control to (or calls) the Nth label, where N is the value of the *expression*.
If N is zero or greater than the number of labels, the program continues with the next command.
ON ERROR GOTO *label* transfers program control to the label when a runtime error occurs (see ERR and RESUME), and ON ERROR GOTO 0 disables it.

OPEN *file* [FOR INPUT|OUTPUT|APPEND|RANDOM] AS [#]*n* [LEN=*reclen*]
Opens *file* as file number *n* (1-4) for reading (INPUT), for writing (OUTPUT, which creates or truncates the file), for adding to the end (APPEND), or without FOR, for random access to records of *reclen* (1-255, default 128) bytes.  See also CLOSE, EOF, INPUT #, LINE INPUT #, PRINT #, and WRITE, and for random access, FIELD, GET #, PUT #, LSET, and RSET.

OPTION BASE 0|1
Sets the smallest subscript (0 or 1) of arrays dimensioned afterward.  The default is 0.

PAINT (*x*,*y*)[,[*paint*][,*border*]]
Fills the area around *x*,*y* with the *paint* color, up to the *border* color (which defaults to the *paint* color).

PEEK(*offset*)
Returns the byte at *offset* in the segment set by DEF SEG.

PLAY *string*
Plays music, using these commands: A-G[#|+|-][*n*][.] (notes), N *n* (note 0-84), O *n* (octave 0-6), < and >, L *n* (length), P *n* (pause), T *n* (tempo), and MN, ML, MS (normal, legato, or staccato).  Any number can be given as =*variable*; (eg, "O=J;").

POKE *offset*,*value*
Stores *value* (0-255) at *offset* in the segment set by DEF SEG.

POS(*n*)
Returns the cursor's column, starting at 1 (*n* is ignored).  See also CSRLIN.

PRESET (*x*,*y*)[,*color*]
Same as PSET, except that the default color is the background color.

PRINT [#*n*,]
Prints a comma or semi-colon separated series of values (or with #*n*, writes them to file *n*).  To send the output of a line to a file instead, end the line with :> *file* (or :>> *file* to append).

PSET (*x*,*y*)[,*color*]
Draws a point in a graphics mode, using the foreground color if no *color* is specified.

PUT (*x*,*y*),*array*[,PSET|PRESET|XOR|OR|AND] or PUT [#]*n*[,*record*]
Draws an image stored by GET, combining it with the screen using XOR, unless another action is specified.
With a file number, writes the FIELD variables of random access file *n* to the specified record (or the next one).

RANDOMIZE [*seed*]
Reseeds the random number generator, so that the same *seed* always produces the same sequence (without a *seed*, the BIOS tick count is used).

RD [*drive*:]*path*
Removes an empty directory, unless it's the current directory of any session.  RMDIR is the same as RD.

READ *variable*[,*variable*]...
Assigns the next DATA item to each variable.  Reading past the last item is an "Out of DATA" error.

REM
Used for program remarks.  The rest of the line is not executed.  An apostrophe (') outside of quotes is the same as REM.

RESET
Same as CLOSE without file numbers (ie, closes all files).

RESTART
Restarts the system.

RESTORE [*line*]
Makes the first DATA item (or the first DATA item at or after *line*) the next item for READ.

RESUME *label*
Ends the handling of a runtime error (see ON ERROR) and continues at the specified label.

RETURN [*expression*]
Returns from a GOSUB subroutine, or ends a function block and returns the specified *expression*.

RIGHT$(*string*,*n*)
Returns the rightmost *n* characters of *string*.

RMDIR [*drive*:]*path*
Same as RD.

RND[(*n*)]
Returns a random number from 0 up to (but not including) 1.  *n* has the same effect as with RND%.

RND%[(*n*)]
Returns a random integer between 0 and MAXINT, inclusive.  If *n* is negative, it reseeds the generator first, and if *n* is zero, the previous random integer is returned.

RSET *variable$*=*string*
Same as LSET, but right-justified.

RUN
Runs the currently loaded BAS or BAT file.
Program files can also be run without the RUN command.
If no file extension is specified, files with COM, EXE, BAT, and BAS extensions are checked, in that order.

SAVE *file*
Saves the currently loaded program as a text file (if no file extension is specified, BAS is used).

SCREEN [*mode*][,*burst*]
Sets the screen mode: 0 (text), 1 (320x200 graphics), or 2 (640x200 graphics).
A *burst* of 0 disables color in mode 0, and a *burst* of 1 disables color in mode 1.
Changing the mode clears the screen and removes the session's border, if any.

SGN(*x*)
Returns -1 if *x* is negative, 0 if *x* is zero, or 1 if *x* is positive.

SIN(*x*)
Returns the sine of *x*, where *x* is in radians.

SOUND *frequency*,*duration*
Plays a tone of the specified *frequency* (37-32767 Hz) for *duration* clock ticks (18.2 per second).
The program continues while the tone plays, but the next SOUND waits for it to finish, unless its *duration* is 0, which stops the tone.

SPACE$(*n*)
Returns a string of *n* spaces.

SPC(*n*)
Same as SPACE$ (eg, PRINT "A"; SPC(5); "B").

SQR(*x*)
Returns the square root of *x*, which must not be negative.

STOP
Same as END.

STR$(*x*)
Returns *x* as a string, with a leading space if *x* is not negative.

STRING$(*n*,*char*)
Returns a string of *n* copies of *char*, which can be either a character code or a string (whose first character is used).

SWAP *variable1*,*variable2*
Exchanges the values of two variables (or array elements) of the same type.

SYSTEM
Same as END.

TAB(*n*)
Returns enough spaces to move the cursor to column *n* (1-254), for PRINT; if the cursor is already past column *n*, the spaces start on the next line.

TAN(*x*)
Returns the tangent of *x*, where *x* is in radians.

TIME [*time*] [-D] [-P]
Sets the system time (or prompts for a time if -P) and then displays the time. -D displays elapsed time.
The time must be entered as H:M:S.D, where where H is 0-23, M is 0-59, S is 0-59, and D is 0-99.
If M, S, or D are omitted, zeros are assumed.

TIME$
Returns the current time as a string in the form HH:MM:SS.

TYPE *file*
Displays the contents of the specified file, or with wildcards (? and *), the name and contents of every matching file.

UCASE$(*string*)
Returns *string* with all lower-case letters converted to upper-case.

VAL(*string*)
Returns the numeric value of *string*, ignoring any blanks.  If *string* does not begin with a number, the result is 0.  The &H (hex) and &O (octal) prefixes are allowed (eg, VAL("&HFF") is 255).

VER
Displays the BASIC-DOS version number and revision.

WEND
Ends a WHILE loop.

WHILE *expression*
Executes the lines up to the matching WEND repeatedly, as long as the *expression* is TRUE (non-zero).

WIDTH 40|80
Sets the number of columns in text mode (which clears the screen).
In SCREEN 1, WIDTH 80 selects SCREEN 2, and in SCREEN 2, WIDTH 40 selects SCREEN 1.

WRITE [#*n*,][*expression*[,*expression*]...]
Prints the values (or with #*n*, writes them to file *n*) separated by commas, with strings in quotes, so that INPUT # can read them back.

*Unsupported Commands*
REN (rename) isn't supported yet.  Files can be created, written, copied, and deleted (eg, with COPY, DEL, and SAVE, or OPEN in a BAS program).
