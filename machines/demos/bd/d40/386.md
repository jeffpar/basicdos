The machine below is a COMPAQ DeskPro 386 with a 16Mhz 80386, 1Mb of memory (640K of it conventional memory), a VGA Color Display, a 1.2Mb and a 1.44Mb diskette drive, and a 20Mb hard disk.  It boots the BASIC-DOS 40-Cols diskette and runs two 40-column consoles side by side; use **SHIFT-TAB** to toggle focus.  The boot sector first displays `System starting...`; press any key (or wait 2 seconds) to boot from the diskette, or press **Esc** to boot from the hard disk instead.  Like the PC AT, the DeskPro 386 has a battery-powered real-time clock, so BASIC-DOS starts with the current date and time (type `DATE` or `TIME` to see them).
