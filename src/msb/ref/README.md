## Microsoft BASIC Reference Build

This directory contains the original reference build of Microsoft BASIC: the open-source files under their original names (eg, `BINTRP.H`), with fixes (`GWEVFIX.ASM` and `MATHFIX.ASM`), and the batch files (`MK.BAT` and `LNK.BAT`) and tools (`MASM106.EXE` and `LINK.EXE`) that built `GWBASIC.EXE`, along with IBM's `BASICA.EXE` and hex dumps of both executables for comparison.
