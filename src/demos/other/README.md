## Other BASIC-DOS Demos

This directory contains demos that are only on the BASICDOS-20MB hard disk (in **DEMOS**), not on the diskettes: `CLOCK.BAS`, `TETRIS.BAS`, and `PUBLIC.zip` (whose files, such as `JIVE.EXE`, are extracted onto the disk).  See the [demos README](../README.md) for where they came from.
