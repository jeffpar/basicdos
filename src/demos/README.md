## Notes Regarding Selected BASIC Demos

1. ATAXX: A game of infection on a 7x7 board against the computer, like the Palm Pilot's Ataxx, centered on any console of 40 or more columns; its computer opponent comes from SUCKS1.C, in [tools/dos/demos](../tools/dos/demos/), a solver for the same game (see its comments for the rules).

2. BROGUE: A dungeon of rooms full of stones that roll when pushed, on an 80-column display or VT100; `BROGUE /M` plays with the BROGUEs in other sessions. See [BROGUE.md](BROGUE.md) for the rules, multiplayer, and an example level.

3. CLOCK (in other, so it's only on the hard disk): From https://github.com/robhagemans/hoard-of-gwbasic/blob/master/PeatSoft/clock/Clock1.asc

4. DALEKS: The classic chase, in one large room per level, with teleports and sonic screwdrivers, in the same style as BROGUE (see its comments for the rules).

5. SIEVE: From https://archive.org/details/byte-magazine-1981-09/page/n181

6. TETRIS (in other, so it's only on the hard disk): From https://bisqwit.iki.fi/jutut/kuvat/programming_examples/gwbasictetris.bas
