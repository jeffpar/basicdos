## BASIC-DOS BASIC Utilities

This directory contains the DOS-style utilities that don't need the speed of assembly language, written as BASIC programs (eg, `ATTRIB`, `CHKDSK`, `FORMAT`, `LS`, `MODE`, `SYS`, and `TREE`), which are copied as-is to **EXT\\BAS** on a BASIC-DOS disk.  Each one starts with comments that give its usage, and they all follow the same layout and error-handling conventions (see `AGENTS.md` in the repository root).
