## BASIC-DOS External Utilities

This directory contains the external commands: [bas](bas/) has the ones written in BASIC, [misc](misc/) has the single-file assembly-language ones (the filters and HELP), and each larger utility has its own directory: [vi](vi/) (the `VI.COM` text editor) and [v86](v86/) (`V86.COM`).  On a BASIC-DOS disk, the assembly-language commands are in **EXT\\CMD** and the BASIC ones are in **EXT\\BAS**.
