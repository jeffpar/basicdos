KEYS
The following keys are available when editing command lines:
CTRL-E  Up          CTRL-X  Down\
CTRL-S  Left        CTRL-D  Right\
CTRL-W  Home        CTRL-R  End\

	%s  string\

The brackets show the processor's mode: <> in real mode, [] in protected mode, or () in V86 mode.  The default is "%l%s%g".

[b+]PUT (*x*,*y*),*array*[,PSET|PRESET|XOR|OR|AND] or PUT #*n*[,*record*]
Draws an image stored by GET, combining it with the screen using XOR, unless another action is specified.
With a file number, writes the FIELD variables of random access file *n* to the specified record (or the next one).

[b+]RANDOMIZE [*seed*]
Reseeds the random number generator, so that the same *seed* always produces the same sequence (without a *seed*, the BIOS tick count is used).

[c]RD [*drive*:]*path*
Removes an empty directory, unless it's the current directory of any session.

[b]READ *variable*[,*variable*]...
Assigns the next DATA item to each variable.  Reading past the last item is an "Out of DATA" error.

[b]REM *remark* or ' *remark*
Used for program remarks.  The rest of the line is not executed.

[c]REN *source* *destination*
Renames or moves one file or directory on the same drive (a *destination* that's a directory keeps the name).  Wildcards, open files, and existing destination files aren't allowed.

[b]RESTORE [*line*]
Makes the first DATA item (or the first DATA item at or after *line*) the next item for READ.

[b]RESUME *label*
Ends the handling of a runtime error (see ON ERROR) and continues at the specified label.  RESUME without a label and RESUME NEXT aren't supported.

[b]RETURN [*expression*]
Returns from a GOSUB subroutine, or ends a function block and returns the specified *expression*.

[f]RIGHT$(*string*,*n*)
Returns the rightmost *n* characters of *string*.

[f+]RND[(*n*)]
Returns a random number from 0 up to (but not including) 1.  *n* has the same effect as with RND%.

[f+]RND%[(*n*)]
Returns a random integer between 0 and MAXINT, inclusive.  If *n* is negative, it reseeds the generator first, and if *n* is zero, the previous random integer is returned.

[b+]RSET *variable$*=*string*
Same as LSET, but right-justified.

[b]RUN [*file*]
Runs the loaded BAS or BAT program, or loads BAS *file* (searching PATH$ if necessary) and runs it, clearing variables and closing files.  In a program, RUN restarts it, and RUN *file* replaces it (as CHAIN does).

[b]SAVE *file*
Saves the loaded program as a text file (if no file extension is specified, BAS is used).

[b+]SCREEN [*mode*][,*burst*]
Sets the screen mode: 0 (text), 1 (320x200 graphics), or 2 (640x200 graphics), clearing the screen if the mode changes.  A *burst* of 0 disables color in mode 0, and a *burst* of 1 disables color in mode 1.
SCREEN(*row*,*col*[,*z*])
Returns the character code at *row* and *col*, or its attributes if *z* is non-zero.

[e]SED [~I] [~N] *script* [*file*]
Runs the commands in *script* (separated by ;) on each line of input (or *file*), and then displays the line (eg, DIR | SED s/BAS/BAK/).  The commands are s/*regex*/*text*/[g][p] (substitute), d (delete), p (display), q (quit), and = (display the line number), and each can start with an address (eg, a line number) or range.
Options:\
	~I  Ignore case\
	~N  Don't display each line

[f+]SGN(*x*)
Returns -1 if *x* is negative, 0 if *x* is zero, or 1 if *x* is positive.

[f]SIN(*x*)
Returns the sine of *x*, where *x* is in radians.

[e]SLEEP *seconds*
Waits the specified number of *seconds*.  Press CTRL-C to stop waiting.

[e]SORT [~R] [~+*n*] [*file*]
Displays the lines of input (or *file*) in sorted order, ignoring case (eg, DIR | SORT).  Up to 64K of text can be sorted.
Options:\
	~R   Reverse the order\
	~+*n*  Sort from column *n*

[b+]SOUND *frequency*,*duration*
Plays a tone of the specified *frequency* (37-32767 Hz) for *duration* clock ticks (18.2 per second), while the program continues.  A *duration* of 0 stops the tone.

[f]SPACE$(*n*)
Returns a string of *n* spaces.

[f]SPC(*n*)
Same as SPACE$ (eg, PRINT "A"; SPC(5); "B").

[f]SQR(*x*)
Returns the square root of *x*, which must not be negative.

[c+]START [~B] [*program* [*arguments*]]
Runs *program* in a new session, on a new console that gets the focus (press Shift-Tab, or CTRL-\ on a terminal, to switch consoles); both close when the program ends.  START alone lists the active sessions.
Options:\
	~B  Start in the background (and display the session's number)

[b]STOP [*n*]
Same as END.

[f]STR$(*x*)
Returns *x* as a string, with a leading space if *x* is not negative.

[f]STRING$(*n*,*char*)
Returns a string of *n* copies of *char*, which can be either a character code or a string (whose first character is used).

[b+]SWAP *variable1*,*variable2*
Exchanges the values of two variables (or array elements) of the same type.

[e]SYS *drive*: [~N]
Copies the system files from the system drive (the drive COMMAND.COM was loaded from) to *drive* and makes it bootable, without reformatting it.
Options:\
	~N  Remove the boot message

[f+]TAB(*n*)
Returns enough spaces to move the cursor to column *n* (1-254), for PRINT.

[f]TAN(*x*)
Returns the tangent of *x*, where *x* is in radians.

[e]TEE [~A] *file*
Copies input to output and to *file* (eg, DIR | TEE DIR.TXT | MORE).
Options:\
	~A  Append to *file*

[c]TIME [*time*] [~D] [~P]
Sets the system time (H:M:S.D, where H is 0-23) and displays it, or with no *time*, displays the current time.
Options:\
	~D  Display the elapsed time\
	~P  Prompt for a new time

[f+]TIME$
Returns the current time as a string in the form HH:MM:SS.

[f+]TIMER
Returns the number of seconds since midnight, with hundredths (eg, 45296.17).

[e]TR [~C] [~D] [~S] *set1* [*set2*]
Copies input to output, replacing each character in *set1* with the matching character in *set2* (eg, DIR | TR a-z A-Z).
Options:\
	~C  Use characters not in *set1*\
	~D  Delete characters in *set1*\
	~S  Squeeze repeated characters

[e]TREE [*drive*:][*path*] [~F] [~A]
Displays the directories below *path* (or the current directory) as a tree.
Options:\
	~F  List files also\
	~A  Use ASCII characters

[f]TRUE
Constant equal to -1, the value that comparisons return when true (so NOT TRUE is FALSE).

[c]TYPE *file*
Displays the contents of the specified file, or with wildcards, the name and contents of every matching file.

[f+]UCASE$(*string*)
Returns *string* with all lower-case letters converted to upper-case.

[e]UNIQ [~C] [~D] [~I] [~U] [*file*]
Displays input (or *file*) with each run of identical lines displayed once, so input is usually sorted first (eg, SORT NAMES.TXT | UNIQ).
Options:\
	~C  Add each line's count\
	~D  Display only repeated lines\
	~I  Ignore case\
	~U  Display only unique lines

[e]V86 [~M:*size*] [*program* [*arguments*]]
Runs a real-mode *program* (COMMAND.COM if none) in a V86 machine, which needs an 80386 in protected mode, with 640K of memory unless ~M is given.  On such a machine, a real-mode EXE file (eg, WOLF3D) runs as if with START V86, unless its input or output is redirected.
Options:\
	~M:*size*  K of memory (4-640)

[f]VAL(*string*)
Returns the numeric value of *string*, or 0 if it doesn't begin with a number.  The &H or 0x (hex) and &O (octal) prefixes are allowed (eg, VAL("&HFF") is 255).

[c]VER
Displays the BASIC-DOS version number and revision letter, if any.

[e]VI [~WS] [*file*]
Edits *file* full-screen with a subset of the UNIX vi editor's commands: press i to insert text and ESC to stop, then type :wq to save and exit, or :q! to exit without saving.
Options:\
	~WS  Add WordStar keys

[b+]VIEW [[SCREEN] (*x1*,*y1*)-(*x2*,*y2*)[,[*fill*][,*border*]]] or VIEW PRINT [*top* TO *bottom*]
Limits drawing in a graphics mode to a viewport (relative to it, unless SCREEN is given), after filling it and drawing a border, if specified.  VIEW alone ends the viewport.
VIEW PRINT limits scrolling to rows *top* through *bottom*, or alone, restores every row.

[e]VOL [*drive*:]
Displays the volume label of *drive* (or the current drive).

[e]WC [~B] [~L] [~W] [~C] [*file*]...
Displays the number of lines, words, and bytes of input (or of each matching *file*).
Options:\
	~B  Count only BASIC code\
	~L  Display only line counts\
	~W  Display only word counts\
	~C  Display only byte counts

[b]WEND
Ends a WHILE loop.

[b]WHILE *expression*
Executes the lines up to the matching WEND repeatedly, as long as the *expression* is TRUE (non-zero).

[b+]WIDTH 40|80|132[,*rows*] or WIDTH *device*,*width*
Sets the number of text columns (which clears the screen) and *rows* (25, 43, or 50).  In SCREEN 1, WIDTH 80 selects SCREEN 2, and in SCREEN 2, WIDTH 40 selects SCREEN 1.  A *device* other than "CON" or "SCRN:" is accepted, but ignored.

[b+]WINDOW [[SCREEN] (*x1*,*y1*)-(*x2*,*y2*)]
Defines the world coordinates of the viewport (or screen) for graphics statements, where y increases upward (or with SCREEN, downward).  WINDOW alone ends world coordinates.

[b]WRITE [#*n*,][*expression*[,*expression*]...]
Prints the values (or with #*n*, writes them to file *n*) separated by commas, with strings in quotes, so that INPUT # can read them back.

*Unsupported Commands*
Files can be created, written, copied, renamed, moved, and deleted (eg, with COPY, REN, DEL, and SAVE, or OPEN in a BAS program).
