## BASIC-DOS Miscellaneous Tests

This directory contains the test programs that aren't regression tests, because each one needs something more (eg, `GFXTESTS.BAS` needs a CGA, `V86TESTS.COM` needs `V86.COM`, and `DBGTESTS.COM` needs the debugger), faults or fails on purpose (`ASSERT.COM` and `FAULT.COM`), measures instead of checking (`MICRO.BAS`), or just runs (eg, `PRIMES.BAT` and `RANDOM.BAT`).
