The BASIC-DOS 40-Cols diskette's **CONFIG.SYS** defines two 40-column consoles side by side, each running its own copy of COMMAND.COM.  The left console runs HELLO.BAT, a batch file that displays a colorful greeting, while the right console runs DIR, which lists the diskette's root directory, and then waits at a prompt for your next command.

Both consoles are configured with borders, and a double-wide border indicates which console has keyboard focus.  Use **SHIFT-TAB** to toggle focus.
