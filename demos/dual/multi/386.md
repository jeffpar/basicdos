The machine below is a COMPAQ DeskPro 386 with a 16Mhz 80386, 1Mb of memory (640K of it conventional memory), two monitors (a Monochrome Display and a Color Display), a 1.2Mb and a 1.44Mb diskette drive, and a 10Mb hard disk.  It boots the BASIC-DOS Multi-Session Demo diskette and runs FOUR sessions, two on each monitor.  Since the machine has a hard disk, the boot sector first displays `Press a key to start...` on the Monochrome Display; press any key (or wait 5 seconds) to boot from the diskette, or press **Esc** to boot from the hard disk instead.  Like the PC AT, the DeskPro 386 has a battery-powered real-time clock, so BASIC-DOS starts with the current date and time (type `DATE` or `TIME` to see them).

Use **SHIFT-TAB** to move keyboard focus from one session to the next.

This demo is also available on an [IBM PC](../pc/), an [IBM PC XT](../xt/), and an [IBM PC AT](../at/).
