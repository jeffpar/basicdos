The machine below is a COMPAQ DeskPro 386 with a 16Mhz 80386, 1Mb of memory (640K of it conventional memory), two monitors (a Monochrome Display and a Color Display), two diskette drives, and a 10Mb hard disk.  It boots the BASICDOS-360K-DUAL diskette and runs one session on each monitor: PRIMES.BAT on the Monochrome Display, while the Color Display switches to the hard disk's **SRC** directory and runs **MK** to build BASIC-DOS itself, with MAKE, MASM, and LINK.  Since the machine has a hard disk, the boot sector first displays `Press a key to start...` on the Monochrome Display; press any key (or wait 5 seconds) to boot from the diskette, or press **Esc** to boot from the hard disk instead.  Like the PC AT, the DeskPro 386 has a battery-powered real-time clock, so BASIC-DOS starts with the current date and time (type `DATE` or `TIME` to see them).

Use **SHIFT-TAB** to move keyboard focus from one session to the next.  For even more sessions, try the [Dueling Monitors](../multi/386/) demo, which runs FOUR sessions, two on each monitor.

This demo is also available on an [IBM PC](../pc/), an [IBM PC XT](../xt/), and an [IBM PC AT](../at/).
