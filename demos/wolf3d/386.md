The machine below is a COMPAQ DeskPro 386 with a 16Mhz 80386, 1Mb of memory (640K of it conventional memory), a VGA Color Display, a Sound Blaster, a 1.2Mb and a 1.44Mb diskette drive, and a 10Mb hard disk.  It boots BASIC-DOS from its hard disk (drive C:) and then types `WOLF3D` at the prompt, which runs the shareware version (1.4) of [Wolfenstein 3D](https://www.pcjs.org/software/pcx86/game/id/wolf3d/) from the hard disk's DEMOS\WOLF3D directory.

{% include machine.html id="deskpro386" %}

Click the screen to give the game the keyboard.  Press any key to get past the opening screens, use the arrow keys to move, **Ctrl** to fire, **Space** to open doors, and **Esc** for the menu; quitting the game returns to the BASIC-DOS prompt.  Any changes you make to the hard disk are lost when you leave the page.

This demo is also available on an [IBM PC AT](../at/).
