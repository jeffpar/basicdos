The machine below is a COMPAQ DeskPro 386 with a 16Mhz 80386, 1Mb of memory (640K of it conventional memory), a VGA Color Display, a 1.2Mb and a 1.44Mb diskette drive, and a 10Mb hard disk.  It boots the BASIC-DOS HD VT100 Demo diskette and runs two independent sessions: an 80x25 console on the Color Display, and a console on a DEC VT100 terminal connected to COM1.  Like the PC AT, the DeskPro 386 has a battery-powered real-time clock, so BASIC-DOS starts with the current date and time (type `DATE` or `TIME` to see them).

{% include vt100-demo.html id="deskpro386" %}

Press any key on the Color Display at the boot prompt (or wait 5 seconds) to start the diskette.  Then click the VT100 screen and type a command, such as `DIR` or `PRINT "Hello from the VT100"`; click the Color Display to use the local session.  Changes to the hard disk are lost when you leave the page.

This demo is also available on an [IBM PC XT](../xt/) and an [IBM PC AT](../at/).
